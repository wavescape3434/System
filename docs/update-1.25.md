# Version 1.25.0 — balanced training and comparable results

Objectives → **Regimen** provides a repeatable week with **two full-body strength days**, five walking blocks and a recovery day. The Guild has a direct shortcut. Choose home, weights or gym; F–C prescriptions specify exercises, sets, reps, rest, effort, technique and progression. Walking difficulty is independent.

- F begins with one short work set of each movement. A/B sessions cover legs, push, row, hinge and trunk. E/D/C add controlled training volume and harder variations/load.
- Log actual sets, setup, external load and clean reps left. Unfinished logs survive a reload on the same device; failed saves preserve the draft. Metric and imperial inputs store canonical kilograms.
- Compare the same exercise/setup/load. Repeated top-range work suggests progression; a multi-session review suggests checking the next rank. Neither changes stats or plan rank automatically.
- Strength-class commissions and calendar goals adapt to the chosen dose and two-day schedule. Hybrid classes retain their secondary focus checklist. Universal sessions pay once; 48-hour hard-strength overlap rules apply.
- Manually take two-day weekly or eight-day monthly regimen commitments. Existing accepted prescriptions stay intact after plan edits. Calendar expiry and no automatic renewal remain.
- Common physical requests now specify clearer technique, rest and progression. Running intervals have an exact 28-minute total. High-volume pullups/pushups are labeled endurance challenges, not the default strength programme.
- Optional knowledge results retain subject/source and checked correct/attempted counts, including zero; Journey separates topic accuracy and exercise reps/load trends.
