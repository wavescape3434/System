# Theo Martin — Data Analyst

**Fictional customer; scripted app outcomes. The experience assessment below is an inference, not a testimonial.**

## Background

Theo is in his first analyst job and enjoys learning systems quickly. He is also the cohort’s deliberate exam-avoidance case: he keeps submitting work but initially ignores milestone tests. He wants a powerful caster and expects accumulated XP to be enough. This profile tests whether the distinction between banked experience and certified level becomes frustrating.

## Goals and intended use

- **Scenario career output:** A fictional cleaned dataset with checks and a reproducible chart.
- **Learning focus:** Data cleaning and interpretation.
- **Class ambition:** Archmage → Astral Savant. The chosen class is independent of the profession.
- **Constraints:** Continues ordinary practice but declines all milestone exams in the primary scenario.

## Experience assessment

This is the clearest exam-friction case. The primary run deliberately refuses exams while continuing the same work. His career tree and player level still advance, but the certified class/profession levels stop at 4. The matched review run shows why an actionable exam prompt matters without removing the gate.

With the matched review policy, the same player Lv. 69 account ends at Scholar 20 / Data Analyst 104, versus 4 / 4 here. The work, player XP and wallet match; exams change certified progression.

Current aspiration: **Astral Savant**. Remaining requirements: INT 50; Archmage Lv. 40; Astral Savant entry trial.
