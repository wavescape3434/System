# Regimen previews and screen checks

Run `node scripts/capture-regimen.mjs` against the local Vite server. It uses fresh sample Warrior characters, a fixed 1 February 2027 date in America/Denver, and no earned-work history. The gym sample has equipment enabled and a selected E plan; imperial mode changes input units only. An entered 8-rep set and 22-lb load illustrate unfinished input, not observed exercise.

Eight views cover plan settings, the F home prescription, expanded technique, actual-set form, a weekly parchment request, E gym desktop, imperial input and 125% root text on a 390px phone. Images are in the [gallery](../../screenshots/README.md); [axe-core results](scans.json) record each viewport, horizontal overflow and automated WCAG A/AA findings. Script errors are retained. These scans do not establish full accessibility or installed Android behavior.
