# Changes — 1.26.0

Objectives now select a difficulty from demonstrated activity or a declared subject proficiency, rather than simply opening the first available rank. Strong pushing is separated from full-body volume: 35 consecutive floor pushups selects harder floor practice, while independent leg/hip/core setups avoid assuming that one test establishes all-round fitness.

All twenty career categories and twenty-five vocations have F–C daily variants. Ability settings store a subject, current level and checkable criterion/source for class focus, profession, vocation and universal activity. Retrieval, correction, unfamiliar cases, constraints and verification distinguish the work. Comparable logged topic results can suggest a difficulty review, without automatically promoting a character or changing a plan.

New registration defaults to imperial and asks for a one-mile time in minutes and seconds. Walking and running are separate protocols; the six-minute walk and old results remain supported. The mile time's game anchor is explicitly provisional and is not a VO₂max estimate or a published adult average.

INT now uses original logic/reasoning problems. WIS includes uncertainty, intuitive errors, prediction and evidence. CHA uses spoken explanations, summaries and teach-back with an anchored self-review, practice timers and optional temporary local recording. Microphone permission is requested only after Record. New forms are v3; old v2 results and scores remain readable. Different versions establish a new exam baseline and separate history series. Finishing faster alone cannot pass a v3 improvement exam; older mastery evidence does not count as demonstrated improvement on a new form family.

The original stat names remain. A separate [seven-attribute fantasy proposal](proficiency-1.26/STAT-PROPOSAL.md) is provided for discussion before any migration.

The development preview also ignores copied native Android build assets, preventing unrelated page reloads during native builds.

Also correct Network Weaver's forward request ownership/filter collision; preserve taken prescriptions and earned amounts; improve mile control sizing and assessment contrast; and let informational toast text stop intercepting request actions while retaining its dismissal button.

No guild XP thresholds, reward prices, existing paid skills, histories, continuous-field adventure rules, companion progression or midnight recovery rules are changed. Google setup remains deferred.
