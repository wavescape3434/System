# Version 1.19.0 — six more profession tools

P07 now covers **fourteen of twenty** career disciplines. Learn either the listed profession root or its opening primer, then use the tool from the skill panel, profession record or Adventures → Fieldwork. Ownership remains after changing profession.

| Discipline | Tool | Use |
| --- | --- | --- |
| Engineering | Pathwright’s Route Plan | Choose a destination, see its remaining prerequisite stages and open the next reachable route. Existing and preserved access count. |
| Science | Naturalist’s Field Record | Filter observed exploration outcomes/materials by area, inspect lifetime confirmed defeats separately and export a text record. |
| Healthcare | Chirurgeon’s Triage | Inspect current party reserves, capped potion/ether recovery, unused capacity and the next local-midnight rest. Fallen companions cannot receive these items. |
| Education | Tutor’s Battle Primer | Read the next uncleared stage’s shells/heavy attacks and the party’s equipped shell breakers/defenses with actual MP readiness. Open the skill loadout. |
| Law | Guild Advocate’s Writ | Review commission terms, hunt acceptance baselines, delivery consumption, once-only dungeon terms, report location and linked calendar conditions. |
| Community Services | Companions’ Service Roster | Check recruitment stages, route access, eligibility, recruited status and active-party membership. Open the actual party screen. |

These are information and preparation uses. Viewing them awards no XP, gold, items, base stats, healing or recruitment. Ordinary board, battle, shop and party actions still perform transactions. Field records describe game observations; they do not certify real-world professional competence.

Science’s event counts cover the matching entries in the journal’s last 120 records. Lifetime defeats use separate confirmed-kill counters. These scopes are shown in the interface and text export; neither is presented as an inferred drop probability.

Fieldwork remains one selected tool. New party/loadout shortcuts join the existing map, shop and commission shortcuts. During an expedition, closing Fieldwork retains the expedition and its reserves; explicitly opening another destination leaves it. Help documents these behaviors.

No character-schema migration or new dependencies. Android version **1.19.0 / code 21** retains the package and signing certificate. Real-world progression rewards, rank thresholds and local-midnight recovery rules remain unchanged.

Six career toolkits remain: Creative, Sales, Administration, Hospitality, Manufacturing and General Practice. P08 economy/build balance and P05 physical-device reliability remain open. Google setup stays deferred by the owner.
