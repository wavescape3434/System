# Version 1.13.0 — universal boards and skill constellations

Universal requests now sit behind **Strength, Dexterity, Constitution, Intelligence, Wisdom and Charisma** boards. Each board shows its matching request count for the current daily/weekly/monthly page and search/filter settings. Open a board to browse its requests, choose a rank, pin it or take it. **All boards** returns to the hall. Class, profession and vocation requests remain directly listed. Taken continues to combine accepted work across scopes and cadences; it never requires opening a stat board.

Search narrows the board counts before a universal board is opened. Pinned and Suggested follow the same universal-board structure. The selected board survives reload within the current session. Existing commitments, pins and rewards keep their original rules.

Skill trees now use **connected constellations** with distinct combat-style filters. Fighter has Vanguard, Counterguard and Battlecraft plus Swordsmanship, Spearcraft, Axe Fighting and Unarmed Combat. The other seven archetypes have their own named styles. Universal skills spread across six attribute paths; profession constellations retain the shared career disciplines and credential branches.

Style filters retain prerequisite nodes, including alternate routes through another style. Solid links are mandatory prerequisites; dashed links are one-of choices. The selected-skill panel shows the actual adventure effect, MP cost, equipped combat modifier, level, practice progress, point price and unmet requirements. Prerequisite names are clickable. The panel stays beside the map on desktop and opens as a lower sheet on phones, leaving the upper map available.

Purchased combat skills can be equipped directly from the panel. The same validated action is used by the Adventure loadout: only earned combat skills qualify, four slots remain available, and loadout changes are blocked during an active fight. Base stats do not change when learning or equipping a skill.

**Available skills**, **Fit**, pinch zoom, dragging and the searchable skill list remain available. Search and status controls highlight map matches and filter the list. A skill goal highlights its prerequisite network, including alternate choices. Goals and viewport preferences survive reload within the current session; they are view preferences, separate from earned character progress and exported backups. Level gates are collapsible.

Existing skill IDs, purchases, point costs, practice requirements, combat behavior, class records and skill ownership remain in place. This update reorganizes their presentation and navigation; it does not reset or refund earned skills.
