# Install The Guild on Android

Open `the-guild-debug.apk` in this folder on GitHub, then select **Download raw file** (the download arrow). Open the downloaded APK on your Android phone. Android may ask you to allow installations from your browser or file manager.

Requires Android 7.0 or newer. This is a signed development build for personal testing, not a Play Store release. Google sign-in and cloud backups need the Firebase/OAuth configuration described in the main README; the local app works without it.

The checksum is in `the-guild-debug.apk.sha256`. Visual previews are in `docs/screenshots/` at the repository root. All screenshots use the sample character, not personal progress.

The APK is included directly in this repository, so you do not need Android Studio or build tools to try it. If GitHub asks you to sign in, use the account that has access to this repository.
